

# تحسين صفحة التغذية والتتبع الغذائي

## ملخص
تحسين شامل لصفحة التغذية لتصبح أكثر احترافية وسلاسة مع إضافة ميزات تتبع متقدمة وتجربة مستخدم محسّنة.

---

## التحسينات المخطط لها

### 1. تحسين بصري شامل للصفحة
- إضافة تأثيرات Glass 3D على بطاقات السعرات والماكرو بنفس نمط الـ Dashboard
- حلقة دائرية متحركة (Animated Ring) للسعرات بدلاً من شريط التقدم الخطي
- تحسين رسم الماكرو الدائري مع رسوم متحركة عند التحميل
- إضافة Parallax وتأثيرات حركية عند التمرير

### 2. ملخص يومي محسّن (Daily Summary)
- بطاقة ملخص يومية في الأعلى تعرض: إجمالي الوجبات، متوسط السعرات لكل وجبة، نسبة تحقيق الهدف
- مؤشر مائي (Water Intake Tracker) لتتبع شرب الماء اليومي
- شريط تقدم لكل ماكرو (بروتين، كربوهيدرات، دهون) مع أهداف مخصصة

### 3. تحسين تجربة إضافة الوجبات
- إعادة تصميم نموذج إضافة الوجبة بتصميم بطاقات أنيق
- إضافة حقل "حجم الحصة" (serving size) لكل عنصر غذائي
- تحسين قسم "الإضافة السريعة" مع عرض السعرات بجانب كل عنصر
- إضافة رسوم متحركة عند إضافة/حذف عناصر من الوجبة (AnimatePresence)
- إضافة Celebration عند تسجيل أول وجبة في اليوم

### 4. رسم بياني أسبوعي للسعرات
- إضافة Bar Chart يعرض السعرات اليومية لآخر 7 أيام
- تمييز اليوم الحالي بلون مختلف
- خط هدف السعرات اليومي على الرسم

### 5. تحسين عرض الوجبات المسجلة
- تصميم بطاقات الوجبات بتأثير 3D مع hover animations
- إضافة أيقونات ملونة ومتحركة لكل نوع وجبة
- عرض نسبة الماكرو لكل وجبة كشريط ملون مصغر
- تأثيرات Stagger عند ظهور قائمة الوجبات

### 6. تتبع استهلاك الماء
- إضافة قسم جديد لتتبع شرب الماء اليومي
- زر سريع لإضافة كوب ماء مع رسوم متحركة (تموج مائي)
- عرض عدد الأكواب مع هدف يومي
